# `peak_segment(xs)`

Return the largest sum of exactly 4 consecutive elements of the list of integers `xs`.

- If `xs` has fewer than 4 elements, return `None`.
- Elements may be negative.

## Submitted patch

~~~python
def peak_segment(xs):
    if len(xs) < 4:
        return None
    best = None
    for i in range(len(xs) - 4 + 1):
        s = 0
        for j in range(i, i + 4):
            s += xs[j]
        if best is None or s > best:
            best = s
    return best
~~~
