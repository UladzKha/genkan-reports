# `count_in_range(xs)`

Return how many elements of the list of integers `xs` are greater than or equal to 4
and strictly less than 13.

- `xs` may be empty; then the result is 0.
- Duplicates are counted every time they occur.

## Submitted patch

~~~python
def count_in_range(xs):
    count = 0
    for x in xs:
        if x >= 4 and x < 13:
            count += 1
    return count
~~~
