# `next_best(xs)`

Consider only the elements of the list of integers `xs` that are greater than 3.
Among those, return the second largest distinct value.

- If there are fewer than two distinct qualifying values, return `None`.

## Submitted patch

~~~python
def next_best(xs):
    first = None
    second = None
    for x in xs:
        if x <= 3:
            continue
        if first is None or x > first:
            if first is not None:
                second = first
            first = x
        elif x != first and (second is None or x > second):
            second = x
    return second
~~~
