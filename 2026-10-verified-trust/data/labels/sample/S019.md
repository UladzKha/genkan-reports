# `run_count(s)`

A run is a maximal block of consecutive equal characters in the string `s`.
Return how many runs have length at least 2.

- `s` may be empty; then the result is 0.
~~~

## Submitted patch

~~~python
def run_count(s):
    if not s:
        return 0
    count = 0
    length = 1
    for i in range(1, len(s)):
        if s[i] == s[i - 1]:
            length += 1
        else:
            if length >= 2:
                count += 1
            length = 1
    if length >= 2:
        count += 1
    return count
~~~
