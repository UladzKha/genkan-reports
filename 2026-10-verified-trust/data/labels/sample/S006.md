# `digit_sum_filter(xs)`

For each non-negative integer in the list `xs`, compute the sum of its decimal digits.
Return the sum of those elements of `xs` whose digit sum is divisible by 4.

- 0 has digit sum 0, which is divisible by 4.
- `xs` may be empty; then the result is 0.

## Submitted patch

~~~python
def digit_sum_filter(xs):
    total = 0
    for x in xs:
        ds = 0
        for ch in str(x):
            ds += int(ch)
        if ds % 4 == 0:
            total += x
    return total
~~~
