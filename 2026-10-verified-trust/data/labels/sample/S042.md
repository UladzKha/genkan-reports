# `max_window_sum(xs)`

Return the largest sum of exactly 3 consecutive elements of the list of integers `xs`.

- If `xs` has fewer than 3 elements, return `None`.
- Elements may be negative.

## Submitted patch

~~~python
def max_window_sum(xs):
    if len(xs) < 3:
        return None
    best = None
    for i in range(len(xs) - 3 + 1):
        s = 0
        for j in range(i, i + 3):
            s += xs[j]
        if best is None or s > best:
            best = s
    return best
~~~
