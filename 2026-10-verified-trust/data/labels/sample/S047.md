# `max_window_sum(xs)`

Return the largest sum of exactly 2 consecutive elements of the list of integers `xs`.

- If `xs` has fewer than 2 elements, return `None`.
- Elements may be negative.

## Submitted patch

~~~python
def max_window_sum(xs):
    if len(xs) < 2:
        return None
    best = None
    for i in range(len(xs) - 2 + 1):
        s = 0
        for j in range(i, i + 2):
            s += xs[j]
        if best is None or s > best:
            best = s
    return best
~~~
