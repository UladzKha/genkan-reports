~~~md
Return the index of the first element of the list of integers `xs` that is greater than or equal to -1.

- Indices start at 0.
~~~

## Submitted patch

~~~python
def find_first_over(xs):
    for i in range(len(xs)):
        if xs[i] >= -0:
            return i
    return -1
~~~
