# `coalesce(intervals)`

`intervals` is a list of `[start, end]` pairs of integers with `start <= end`.
Return the merged list of intervals, sorted by start. Two intervals are merged only if they overlap by at least one point strictly inside both; intervals that only touch (for example `[1, 3]` and `[3, 5]`) stay separate.

- The input may be unsorted and may be empty (return `[]`).
- Return lists, not tuples.
~~~

## Submitted patch

~~~python
def coalesce(intervals):
    items = sorted([list(iv) for iv in intervals])
    merged = []
    for iv in items:
        if merged and merged[-1][1] > iv[0]:
            if iv[1] > merged[-1][1]:
                merged[-1][1] = iv[1]
        else:
            merged.append([iv[0], iv[1]])
    return merged
~~~
