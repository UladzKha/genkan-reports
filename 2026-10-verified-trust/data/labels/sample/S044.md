## Task statement

~~~md
# `count_in_range(xs)`

Return how many elements of the list of integers `xs` are greater than or equal to -5
and strictly less than 5.

- `xs` may be empty; then the result is 0.
- Duplicates are counted every time they occur.
~~~

## Submitted patch

~~~python
def count_in_range(xs):
    count = 0
    for x in xs:
        if x >= -5 and x < 5:
            count += 1
    return count
~~~
