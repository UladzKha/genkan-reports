## Task statement

~~~md
# `spin(xs, k)`

Return a new list: `xs` rotated to the right by `k + 1` positions. The last element moves to
the front on each single step.

- `k` is a non-negative integer and may be larger than `len(xs)`.
- If `xs` is empty, return `[]`.
- Do not modify `xs`.
~~~

## Submitted patch

~~~python
def spin(xs, k):
    n = len(xs)
    if n == 0:
        return []
    steps = (k + 1) % n
    result = []
    for i in range(n):
        result.append(xs[(i - steps) % n])
    return result
~~~
