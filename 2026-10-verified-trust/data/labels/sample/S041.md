# `is_well_nested(s)`

Return `True` if the brackets in the string `s` are balanced and correctly nested, otherwise
`False`. The bracket pairs are: `{}`, `<>`. Every other character is ignored.

- The empty string is balanced.

## Submitted patch

~~~python
def is_well_nested(s):
    opens = '{<'
    closes = '}>'
    stack = []
    for ch in s:
        if ch in opens:
            stack.append(ch)
        elif ch in closes:
            if len(stack) == 0:
                return False
            if opens.index(stack[-1]) != closes.index(ch):
                return False
            stack.pop()
    return len(stack) == 0
~~~
