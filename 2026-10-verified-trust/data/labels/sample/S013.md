# `locate_threshold(xs)`

Return the index of the first element of the list of integers `xs` that is strictly greater than 25.

- If no element qualifies (or `xs` is empty), return -1.
- Indices start at 0.

## Submitted patch

~~~python
def locate_threshold(xs):
    for i in range(len(xs)):
        if xs[i] > 25:
            return i
    return -1
~~~
