# `count_long_runs(s)`

A run is a maximal block of consecutive equal characters in the string `s`.
Return how many runs have length at least 3.

- `s` may be empty; then the result is 0.

## Submitted patch

~~~python
def count_long_runs(s):
    count = 0
    length = 0
    for i in range(len(s)):
        if i > 0 and s[i] == s[i - 1]:
            length += 1
        else:
            if length >= 3:
                count += 1
            length = 1
    if length >= 3:
        count += 1
    return count
~~~
