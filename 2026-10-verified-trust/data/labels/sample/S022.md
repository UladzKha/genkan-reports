# `tally_window(xs)`

Return how many elements of the list of integers `xs` are greater than or equal to 3
and strictly less than 15.

- `xs` may be empty; then the result is 0.
- Duplicates are counted every time they occur.
~~~

## Submitted patch

~~~python
def tally_window(xs):
    count = 0
    for x in xs:
        if x >= 3 and x < 15:
            count += 1
    return count
~~~
