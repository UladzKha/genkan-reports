# `next_best(xs)`

Consider only the elements of the list of integers `xs` that are greater than 4.

## Submitted patch

def next_best(xs):
    vals = sorted({x for x in xs if x > 4})
    if len(vals) < 2:
        return None
    return vals[-2]
